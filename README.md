# Employee Manager

A simple React-based employee management application.

## 📦 Features

- View a list of employees
- Add new employees
- Remove employees
- Mark employees for promotion (`rise`)
- Highlight employees with salary increase
- Search and filter employees
  - Filter by promotion eligibility
  - Filter by salary over 1000
